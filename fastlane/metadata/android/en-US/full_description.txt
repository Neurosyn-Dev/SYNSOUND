<p>SynSound for Android is an open-source Android application that provides a secure WebView client for the hosted SynSound acoustic-analysis service.</p>

<h2>Android application features</h2>
<ul>
<li>Native Android application shell and WebView integration.</li>
<li>Microphone permission mediation for the hosted web application.</li>
<li>Navigation, session persistence, file selection and downloads, and network/error recovery.</li>
<li>On supported Android System WebView versions, a native acoustic-event detector can analyze bounded mono PCM frames tapped from the hosted application's already-active Web Audio microphone stream while monitoring is active.</li>
<li>The native audio tap uses an origin-restricted bridge and does not open a second Android microphone capture.</li>
<li>If the required WebView messaging capability is unavailable, the native audio tap remains inactive rather than falling back to an unrestricted JavaScript bridge.</li>
</ul>

<h2>Important limitations</h2>
<p>The Android APK is a WebView client for the hosted SynSound service. It does not implement every DSP, mastering, transcription, visualization, or forensic workflow as a native Android feature. The hosted web service is proprietary, network-dependent, and uses a fixed service endpoint.</p>
<p>The native event status and candidate labels are heuristic signals, not definitive acoustic or forensic identifications.</p>

<h2>Privacy and network behavior</h2>
<p>The Android APK includes no advertising or analytics SDKs. The native bridge processes the PCM frames it receives in memory and does not itself write those frames to disk or send them to a cloud endpoint. However, microphone audio is supplied to the hosted web application when microphone access is granted. This listing makes no claim that audio remains on-device; the hosted service's own audio and network behavior has not been independently audited.</p>

<h2>Open-source components</h2>
<p>The Android application and Kotlin integration code in this repository are available under the MIT license. The hosted SynSound web service is separate and is not represented as open-source by this Android repository.</p>

<h2>Permissions</h2>
<ul>
<li><strong>RECORD_AUDIO</strong> - Allows microphone access when requested by the hosted SynSound web application.</li>
<li><strong>INTERNET</strong> - Connects to the hosted SynSound service.</li>
<li><strong>ACCESS_NETWORK_STATE</strong> - Supports connectivity handling.</li>
<li><strong>MODIFY_AUDIO_SETTINGS</strong> - Supports Android audio-routing integration.</li>
<li><strong>WRITE_EXTERNAL_STORAGE</strong> - Legacy external-storage access, limited by the manifest to Android 9 and earlier (API 28 and below).</li>
</ul>
