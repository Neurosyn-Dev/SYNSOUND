<p>SynSound is an open-source Android WebView client for the SynSound web application, with a reusable Kotlin SDK for secure Android integration.</p>

<h2>Features</h2>
<ul>
<li>Secure HTTPS-only WebView integration with strict trusted-origin navigation.</li>
<li>Real-time microphone capture through the hosted SynSound web application when Android microphone permission is granted.</li>
<li>Native file selection with multi-file support and secure URI access.</li>
<li>Authenticated downloads from the trusted SynSound HTTPS origin, including legacy Android download handling.</li>
<li>Secure SDK WebView permission forwarding with fail-closed behavior.</li>
<li>HTTPS/WSS-only custom SDK transport configuration.</li>
</ul>

<h2>Privacy and Security</h2>
<p>No ads, analytics SDKs, crash reporters, or Firebase are included. The Android wrapper communicates with the hosted SynSound service over HTTPS. The wrapper does not claim that microphone audio remains on-device; audio processing and network handling are controlled by the hosted web application and its service infrastructure.</p>

<h2>Open Source</h2>
<p>The Android application and SDK source code are available on GitHub under the MIT license.</p>

<h2>Permissions</h2>
<ul>
<li><strong>RECORD_AUDIO</strong> — Required when the hosted SynSound web application requests microphone capture.</li>
<li><strong>INTERNET</strong> — Required to connect to the hosted SynSound web application.</li>
<li><strong>ACCESS_NETWORK_STATE</strong> — Used for connectivity handling.</li>
<li><strong>MODIFY_AUDIO_SETTINGS</strong> — Used for audio routing integration.</li>
<li><strong>WRITE_EXTERNAL_STORAGE</strong> — Requested only on Android 9 and older when saving downloads to public Downloads.</li>
</ul>

<h2>Technical Details</h2>
<ul>
<li><strong>:app</strong> — Android WebView wrapper and native Android system integration.</li>
<li><strong>:sdk</strong> — Reusable Kotlin SDK with secure WebView and transport components.</li>
</ul>

<p>Minimum Android version: Android 8.0 (API 26)<br>
Target Android version: Android 15 (API 35)<br>
Version: 1.0.2 (versionCode 3)</p>
